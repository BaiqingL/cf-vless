# Support

`cf-vless` is an experimental, community-supported project. There is no uptime,
compatibility, or response-time guarantee.

Before opening an issue:

1. read the [troubleshooting guide](docs/troubleshooting.md);
2. run `cf-vless doctor` and `make check`;
3. confirm the behavior against the latest release; and
4. remove every credential, private hostname, account/resource identifier,
   client address, destination, packet capture, and generated client file.

Use GitHub Discussions if enabled for setup questions. Use an issue for a
reproducible bug or a bounded feature proposal. Report vulnerabilities through
the private process in [SECURITY.md](SECURITY.md).

Cloudflare account, billing, abuse, or platform-policy questions belong with
Cloudflare Support. Client-specific behavior outside the documented baseline
belongs with that client's project.
